# 🐾 PetLife

**Site institucional para clínica veterinária**

Projeto desenvolvido com a proposta de criar um site para uma clínica veterinária, apresentando seus serviços e oferecendo aos visitantes uma forma simples de conhecer a clínica.

🔗 **[Acessar o site](petlife-y5a7.onrender.com)**

---

## 📖 Sobre o projeto

A ideia do PetLife surgiu da proposta de desenvolver um site para uma clínica veterinária. O objetivo era criar uma página que transmitisse confiança e acolhimento, utilizando uma identidade visual relacionada ao cuidado com os animais.

## 💻 Como foi desenvolvido

O primeiro passo foi pensar na identidade visual do projeto. Escolhi trabalhar com tons de azul e laranja, buscando combinar uma aparência moderna com elementos que transmitissem proximidade e cuidado.

Depois, comecei a estruturar o site utilizando HTML, organizando as informações em seções como início, sobre nós, serviços, galeria, depoimentos e contato.

Com a estrutura definida, desenvolvi o CSS para trabalhar a aparência das páginas. Nessa etapa, ajustei cores, fontes, espaçamentos, cartões e outros elementos para manter o mesmo padrão visual em todo o site.

Durante o desenvolvimento, também precisei revisar a organização dos arquivos e ajustar o carregamento do CSS para garantir que a estilização fosse aplicada corretamente.

## ⚙️ Seções do site

- Página inicial.
- Sobre a clínica.
- Serviços oferecidos.
- Galeria.
- Depoimentos.
- Contato.
- Botão para agendamento de consulta.

## 🛠️ Tecnologias utilizadas
